> 💡 **Setup Tip:** To activate the snake animation, add the [snk workflow](https://github.com/Platane/snk) to your `Vidanshu24/Vidanshu24` repo under `.github/workflows/snake.yml`.

<details>
<summary><b>📄 Snake Workflow YAML (Click to Copy)</b></summary>

```yaml
# .github/workflows/snake.yml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"  # Runs every 12 hours
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Generate Snake Game from GitHub Contribution Grid
        uses: Platane/snk@v3
        with:
          github_user_name: Vidanshu24
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push Snake to Output Branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
